Essential Technical Viva Q&A

Q1: Which dataset was used, and how is overfitting prevented?

A: PlantVillage dataset (~54,000 images, 38 classes). Overfitting is mitigated via Data Augmentation (rotation, scaling, color jitter), Dropout layers (0.3), and Early Stopping during training.

Q2: Why choose MobileNetV2 over standard CNN from scratch?

A: MobileNetV2 utilizes depthwise separable convolutions, reducing model parameters by ~80% while retaining high ImageNet feature representations, resulting in sub-100ms inference on CPU.

Q3: How are invalid or non-leaf images filtered?

A: Output softmax confidence scores below a designated threshold (e.g., <60%) trigger an out-of-distribution warning prompting the user to upload a clearer leaf photo.
