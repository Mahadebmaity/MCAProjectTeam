# MCA Project Team

## About the Project

This is a collaborative web development project built by a team of MCA students.
The goal of this project is to demonstrate practical skills in frontend web development,
collaborative version control using Git & GitHub, and structured team-based workflows.

---

## Tech Stack

| Technology | Purpose |
|------------|---------|

| CSS3       | Styling & responsive layout |
| JavaScript | Interactivity & DOM manipulation |
| Git/GitHub | Version control & team collaboration |
